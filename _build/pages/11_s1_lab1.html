The mission

Play ball, Task Force.

It's Wednesday, June 16, 2027, 9:00 AM. Riverfront Rally Weekend starts in 48 hours. Dana Whitfield (Promotions) says the plan is locked. Jordan Pierce (Sponsorship) says a new Big River Energy bucket hat giveaway is approved. Marcus Bell (Operations) says it isn't. The warehouse says bobbleheads are covered, but nobody has done the math.

Before you swing at anything, you need an investigation plan: what you need to know, where the evidence lives, and what would count as "confirmed." In this inning you learn the difference between asking Copilot a general question and grounding it in work evidence.

Game plan

  • Explain the difference between a general (web) answer and a grounded (work) answer, and see it happen.
  • Choose between Copilot Chat, Researcher and Analyst for a given question.
  • Write prompts with the 5-Tool Prompt: Goal · Context · Evidence · Constraints · Output.
  • Produce a clear investigation plan for the Rally Weekend readiness question.

Before you start

You only need two files for this inning. Do the setup now anyway, because every later inning uses it: extract the Session 1 kit zip (Copilot can't read inside a .zip), then drag the Rally Weekend Task Force folder into OneDrive.

Rain delay · Work vs. Web

In Microsoft 365 Copilot Chat you may see a Work / Web toggle at the top of the chat. Work grounds answers in your Microsoft 365 content (mail, chats, files you can access). Web answers from the public internet. Some tenants hide the toggle or turn off web grounding. If you don't see it, attach the files directly and you're grounded either way.

The play-by-play

  1. Swing #1: the ungrounded question

    Open Microsoft 365 Copilot Chat. Switch to Web if you have the toggle. Don't attach anything. Ask:

    Is the Riverfront Rally Weekend promotion ready to go? What should we check before the weekend?
    What you should see
    • A polite, generic checklist ("confirm inventory, train staff, communicate with fans…").
    • No mention of bucket hats, Big River Energy, Jordan or Marcus. Copilot has no idea what your weekend is.
    • Possibly confident-sounding filler. That's the danger: it sounds like an answer.

  2. Swing #2: the same question, grounded

    Switch to Work. Attach 03_Event_Plan_v3…docx and 01_Email_Thread_Export.docx. Use the paperclip / + button, or type / and pick the files from OneDrive. Ask the same question, with one added sentence:

    Is the Riverfront Rally Weekend promotion ready to go? What should we check before the weekend? Answer only from the attached event plan and email export. For each point, cite the document or email ID (E01-E16) it comes from.
    What you should see
    • Specifics: the June 4 lock date, the three-part approval rule (E01), the bucket hat dispute (E03-E10), magnets delivered despite cancellation (E13/E14).
    • Citations you can click to open the source.
    • Probably some gaps. It hasn't seen the spreadsheets yet, so it can't know the bobblehead count is short.
    Scouting report · Why grounding matters

    Copilot only knows what it can reach. A grounded answer is only as complete as the evidence you point it at. Part of every investigation is asking, "What hasn't it seen?"

  3. Pick the right player: Chat vs. Researcher vs. Analyst

    Each Copilot tool plays a different position. Match the question to the tool before you start typing.

    ToolPositionUse it when…Rally Weekend exampleSpeed
    Copilot ChatCatcher · home plateQuick, focused questions; drafting; summarizing a few items you can point to."Summarize Marcus's June 2 email."Seconds
    ResearcherScout · 1BMulti-step, multi-source questions that need a structured, cited report. Can combine work and web."Is the weekend actually ready? Cross-check plans, contracts and comms."Several minutes
    AnalystAnalytics dept. · 2BData questions across one or more files: reconciling, trends, outliers, charts. Reasons step by step and can run code."Compare allocations with deliveries and list every discrepancy."A few minutes
    Copilot in ExcelGroundskeeper · 3BChanging a workbook directly: formulas, columns, formatting, PivotTables, charts."Add a Distributable Qty column = Qty - Damaged Qty."Seconds
    Quick quiz: which tool? (click to reveal)
    1. "What did Elena actually say about the bucket hats?" → Chat (one email, quick lookup).
    2. "Do bobbleheads historically lift Saturday attendance?" → Analyst (trend across 163 rows).
    3. "Write a readiness brief covering contracts, ops rules and comms, with sources." → Researcher.
    4. "Highlight every delivery row with a UOM of CS." → Copilot in Excel.

  4. Learn the 5-Tool Prompt

    A five-tool player can hit, hit for power, run, field and throw. A five-tool prompt has five parts too:

    ToolWhat it doesRally Weekend example
    1 · GoalThe decision or deliverable you need."I need to decide whether each promotional element is ready."
    2 · ContextWho you are, the situation, the deadline."I'm on the Task Force. The weekend starts Friday 6/18. A fan email sends Thursday."
    3 · EvidenceExactly which sources to use, and which not to use."Use only the attached event plan and email export."
    4 · ConstraintsRules for honesty and scope."Don't guess. Label anything unconfirmed. Cite email IDs."
    5 · OutputThe exact shape of the answer."A table with columns: Question, Source, Owner, Status."

  5. Live demo: build the investigation plan

    Keep the same two files attached (add any others from the kit you like) and run the full 5-tool prompt:

    GOAL: I need an investigation plan to decide whether each element of the Riverfront Rally Weekend (Fri 6/18 - Sun 6/20, 2027) is ready, before leadership makes a go / no-go call. CONTEXT: I'm on the Riverfront Rally Weekend Task Force. Marketing says the plan is locked, Sponsorship says a new Big River Energy bucket hat giveaway is approved, and Operations says it isn't. Warehouse quantities may not match what was promised to sponsors. A fan email goes to 180,000 fans on Thursday 6/17 at 10:00 AM. EVIDENCE: Use only the attached files. Do not use web results. CONSTRAINTS: Do not decide whether anything is ready yet. Identify what information is needed to make a responsible decision. If the files conflict, say so and name both sources. Mark anything you are inferring as an assumption. OUTPUT: 1. A table with columns: # | Question we must answer | Why it matters | Where the evidence should be (email ID, document, or system) | Who owns the answer | What would count as "confirmed" 2. A short list of the conflicting claims you already see, with sources. 3. The three questions to answer first, given the Thursday 10:00 AM fan email.
    What you should see
    • 8-12 investigation questions covering approvals, contracts, inventory/deliveries, staffing, fan comms and finance.
    • Conflicts already visible: E04 (conditional approval) vs E05/E10 ("approved"); E08 (Marcus: not signed off); E02 cancellation vs E13 delivery.
    • A "confirmed" definition that matches the three-part rule in E01: signed amendment + VP Marketing approval + Ops sign-off.
    Umpire review

    Open at least two cited emails and confirm they say what Copilot claims. Did it notice that Elena's approval says "pending"? Did it list the Excel workbooks as a needed source, even though you didn't attach them? A good plan names the evidence it hasn't seen yet.
