The mission

Stop emailing spreadsheets. Build the tool.

Every "what if" question from leadership (what if Sunday rains, what if we air-freight bobbleheads, what if we take the BRE deal) has meant another round of spreadsheet edits and another email. Elena wants to move the sliders herself in the 3:00 PM meeting.

Use natural language to build a Game-Day Promotion Simulator in Copilot Pages: adjustable assumptions, visible formulas, scenario comparisons, and math you have personally verified. Then survive the Budget Surprise.

Game plan

  • Translate a business question into inputs, rules and outputs.
  • Prompt Copilot to build an interactive prototype and preview it in Pages.
  • Refine the interface and behavior through conversation.
  • Compare conservative, expected and optimistic scenarios.
  • Test edge cases, bad inputs and the math itself.
  • Know what separates a prototype from a production app.

Design before you prompt

Two minutes of design saves twenty minutes of re-prompting. Here's the spec the build prompt encodes.

Inputs

What can change

  • Attendance per game (Fri / Sat / Sun)
  • Margin per attendee: $34
  • Variable opex per attendee: $7
  • Fixed opex: $135,000/game
  • Promo costs: $257,500
  • Sponsorship: $215,000
Rules

How it calculates

Net = A × (Margin − Var) + Sponsorship − Promo − Fixed

Break-even A = (Promo + Fixed − Spons.) ÷ (Margin − Var)

Objective A = ($2.4M + Promo + Fixed − Spons.) ÷ (Margin − Var)

Outputs

What leadership sees

  • Weekend net contribution
  • Gap vs. the $2,400,000 objective
  • Break-even and objective attendance
  • Scenario comparison chart
  • The assumptions, always visible

Play-by-play

  1. Build the first version

    In Copilot Chat, paste the build prompt. It's long on purpose: specific inputs, formulas and defaults are what make the math trustworthy.

    Build an interactive web app called "Game-Day Promotion Simulator" for the fictional Riverfront Rally Weekend (3 home games, June 18-20, 2027). I want to preview and edit it in Copilot Pages. INPUTS (each with a slider and a number box, and a default value): - Attendance Friday (default 36,500), Saturday (39,800), Sunday (33,000). Range 0 to 42,000 per game (ballpark capacity). - Margin per attendee: $34.00 (ticket + concessions + merch, blended net margin) - Variable operating cost per attendee: $7.00 - Fixed operating cost per game: $135,000 (x 3 games) - Promotional costs, as editable line items: Rally Towels $23,000; Retro Bobbleheads $96,000; Kids Mini Bats $28,500; Fireworks $65,000; Entertainment & marketing $45,000 (total $257,500) - Sponsorship contributions, as editable line items: Harbor City Mutual $60,000; Riverbend Health Partners $110,000; Lakeside Fresh Market $45,000 (total $215,000) - Financial objective: $2,400,000 weekend net contribution CALCULATIONS (show these formulas on screen in plain English): - Weekend attendance A = Fri + Sat + Sun - Net contribution = A x (Margin - Variable cost) + Sponsorship - Promotional costs - (Fixed cost per game x 3) - Break-even attendance = (Promotional costs + Fixed costs - Sponsorship) / (Margin - Variable cost), rounded up - Attendance needed for objective = (Objective + Promotional costs + Fixed costs - Sponsorship) / (Margin - Variable cost), rounded up - Gap vs objective = Net contribution - Objective SCENARIOS: buttons that load attendance presets: Conservative (33,500 / 36,500 / 30,000), Expected (36,500 / 39,800 / 33,000), Optimistic (39,500 / 42,000 / 36,000). OUTPUTS: summary tiles for weekend attendance, net contribution, gap vs objective (green "meets objective" or red "below objective", with an icon and text, not color alone), break-even attendance and attendance needed for objective. Add a bar chart comparing net contribution for all three scenarios, with a reference line at $2,400,000. VALIDATION: if margin <= variable cost, show "Break-even undefined" instead of a number. Warn if any game exceeds 42,000 or is negative. Treat blank inputs as an error, not as zero. Style: clean, readable, navy and gold. Format money as $#,### and attendance with thousands separators.
    What you should see
    • A working calculator. With the defaults: 109,300 fans, net $2,503,600, +$103,600 vs. objective.
    • Break-even attendance 16,575. Attendance needed for the objective 105,463.
    • If your tenant supports interactive preview, the result opens (or can be opened) in Copilot Pages, where you can keep editing and share it. If not, see the Rain delay fallback above.

    • Fixed cost counted once instead of × 3 games (net off by $270,000).
    • Variable cost subtracted per game instead of per attendee.
    • Sponsorship subtracted instead of added.

    Iterate one change at a time, and re-test after each.

  5. Prototype vs. production

    Your page is a thinking tool for a meeting, not a system of record. Before it becomes something people rely on, it needs:

    • A data owner (Finance) and a live connection, not typed-in numbers.
    • Version control, review and testing.
    • Access control and a support plan.
    • A clear label on the page: "Prototype · fictional data · validated on June 17 by [[name]]".

Plans that meet the objective:

  • Decline or defer BRE + make-good credit: $2,403,200. Cheapest, but Riverbend may choose a replacement night instead of the credit.
  • Decline BRE + air-freight + a Father's Day concessions bundle (+$0.25 margin per attendee = +$26,500): $2,426,400. Honors the guarantee.
  • Air-freight + ask Skyburst to split the surcharge (−$3,250): $2,403,150.
  • Counter BRE with hats on a later date at standard lead time (10,000 × $4.10 = $41,000), so the fee must be at least about $45,000 to break even.

The big insight: −$100 is well inside forecast error. A Sunday at the conservative 25,000 costs $94,500. The decision should rest on risk and sponsor relationships, not a rounding-error pass or fail. The strongest recommendation is decline or counter BRE + air-freight + the Father's Day bundle ($2,426,400). It keeps the contractual promise and meets the objective. Air-freight + decline alone ($2,399,900) misses by $100. Make the room say why that matters, or doesn't.

Break-even / objective attendance (Plot Twist + surcharge + air-freight): 17,115 and 106,004. Ask the room: "We need four more fans. Is that a plan?"
