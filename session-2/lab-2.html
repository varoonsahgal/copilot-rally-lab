The mission

One dugout for every fact.

Right now the Rally Weekend story lives in a dozen places: an event plan, sponsor terms, an ops playbook, a checklist, yesterday's findings, this morning's memo and a budget workbook. Every new question means attaching the same files again.

Build the Promotional Weekend Command Center: a Copilot Notebook that holds the project's approved sources, follows your instructions every time, and grows as the situation changes. Then find out where its knowledge stops.

☝ Call your shotPredict before you play. Wrong guesses teach the most.

You add BOTH a draft event plan (bucket hats "TBD") and the locked v3 plan to a notebook, with no instructions about which wins. What's most likely?

Without a source hierarchy, both are equally valid to the model. Tell it explicitly: signed contracts > locked plans > emails > transcripts > recaps.

Game plan

  • Explain what a Copilot Notebook is for and how it differs from a chat and an agent.
  • Curate references so answers stay grounded in project content.
  • Use notebook instructions to control format and purpose.
  • Generate a briefing, a risk list and a "then vs. now" comparison.
  • Add new information as the project changes.
  • Find a question the notebook can't answer, and name the missing source.

Rain delay · availability

Copilot Notebooks appear in the Microsoft 365 Copilot app (and in OneNote) for licensed users, subject to admin settings. The kinds of references you can add (files, pages, links, meeting notes) vary by release. No Notebooks, or "Notebook setup did not complete"? If New notebook ends with that message, your account probably lacks the SharePoint storage that notebooks need, and Try again fails the same way. Start one long Copilot Chat, attach all seven files in the first message, paste the notebook instructions from step 2 as your opening prompt, then run the same questions. You lose persistence, but you keep the lesson.

Play-by-play

  1. Create the notebook and add references

    • In the Microsoft 365 Copilot app, select Notebooks → New notebook in the left pane Tested live in M365 Copilot · Nov 2026 and name it Rally Weekend Command Center.
    • Select Next. In the Add to Rally Weekend Command Center dialog, stay on the References tab, search for each file by name and select it. If a file doesn't show up (it may not be in OneDrive yet), use the Upload files icon (Word, Excel, PowerPoint, PDF, text). Then select Create (scroll down if you can't see it). You can add more later from Add references in the notebook's Content pane. Add only approved, current sources. Anything you add becomes part of what Copilot treats as true.
    • Leave the Session 1 email export out on purpose. You'll see why in the challenge.
    Scouting report · curation is the skill

    A notebook is only as trustworthy as its reference list. Ten carefully chosen sources beat fifty "just in case" files: fewer contradictions, sharper answers, easier citations.

  2. Write the notebook instructions

    Instructions set the purpose and format for every answer in this notebook. Open the … menu in the notebook header and select Instructions. Paste these into Tell Copilot how to respond and select Save. They apply to everyone in the notebook. If your version has no Instructions item, send them as the first message.

    Copilot Notebook · instructions
    You are the knowledge hub for the Riverfront Rally Weekend Task Force (fictional, June 18-20, 2027).
Purpose: help the team answer readiness, sponsor, operations and budget questions using ONLY the references in this notebook.
Rules:
1. Cite the reference file for every fact and number.
2. Label every statement as CONFIRMED (in a signed or locked document), ESTIMATE (forecast or projection), or UNRESOLVED (conflicting or missing evidence).
3. When two references disagree, show both and say which is newer. Do not pick a winner silently.
4. If the references do not contain the answer, say "Not in the notebook references" and name the source that would be needed.
5. Prefer the Plot Twist memo (June 17) over older documents for anything it explicitly updates.
Format: start with a 1-sentence bottom line, then bullets or a table. Keep answers under 250 words unless asked for more.

  3. Generate the project briefing

    Copilot Notebook
    Create a one-page readiness briefing for Elena Ortiz as of Thursday June 17, 10:00 AM.
Sections: Bottom line | Game-by-game status (Fri / Sat / Sun) with a GREEN / YELLOW / RED rating | Decisions needed today | Key numbers (attendance, promo cost, sponsorship, net vs the $2.4M objective).
Use the Readiness Checklist rating definitions.
    What you should see
    • Friday GREEN with a cost note (+$6,500 fireworks surcharge).
    • Saturday YELLOW or RED: 600-bobblehead gap, now with a priced fix, and attendance pacing to 41,000.
    • Sunday YELLOW or RED: weather (28,500 expected), the BRE scope decision and the Right Field pallet. RED is fair if it cites the failed approval check on the signed 10,000-hat scope.
    • Net: $2,408,000 on the plot-twist base ($8,000 over the $2.4M objective), or $2,377,100 if it counts the signed hat deal ($25,000 fee against $53,500 hats and $2,400 staff).
    • Citations to the memo, findings, sponsor summary and budget model.

  4. Ask focused, grounded questions

    Run at least two. Notice how short prompts work now: the notebook already knows the project.

    Copilot Notebook
    List every outstanding risk for the weekend. For each: risk | likelihood (H/M/L) | business impact in dollars or fans | owner role | the reference that supports it. Sort by impact.
    Copilot Notebook
    Compare the latest information with our earlier assumptions. Table: Assumption | Earlier value and source | Latest value and source | Change | Does it alter a recommendation? Include Sunday and Saturday attendance, bucket hat quantity and fee, bobblehead shortfall and fix cost, and promo cost total.
    Copilot Notebook
    Under the Ops Playbook approval rule, is the Big River Energy bucket hat now approved? Walk through each of the three requirements and label each MET, NOT MET, or UNKNOWN with a citation.
    What you should see in the then-vs-now table
    • Sunday 33,000 (budget model) to 28,500 (memo). Saturday 39,800 to 41,000.
    • Bucket hats: 5,000 in our draft to 10,000 signed, same $25,000 fee.
    • Bobbleheads: still 600 short; new $8,100 air-freight fix vs the $4,800 make-good.
    • Promo cost: $257,500 to $319,900 if the hat deal goes ahead ($53,500 hats + $2,400 staff + $6,500 fireworks surcharge), $328,000 with air freight.
    What you should see in the approval answer
    • Signed amendment: MET (memo), but the scope changed to 10,000 hats.
    • VP Marketing approval: UNKNOWN / NOT MET. The 5/24 approval was conditional and covered 5,000 hats.
    • Ops capacity sign-off: NOT MET / UNKNOWN. Nine more staff are needed, with no confirmation in the references.

  5. Add new information as the project moves

    Projects change. Simulate a new update: create a notebook page (New Page in the Content pane, if you have it) or a short Word doc called Update - Ops 11AM with the text below and add it as a reference.

    New reference note
    Update - Thursday June 17, 11:00 AM (Marcus Bell, Ballpark Operations)
Staffing agency confirmed 6 additional gate staff for Sunday, not 9.
Right Field mini bat pallet DLV-2234 has been rescheduled from 6/21 to 6/18.
Magnet schedules have been pulled back to the Central Warehouse.
    Copilot Notebook
    What changed with the 11:00 AM Ops update? Which risks can we close, which got worse, and does it change the bucket hat decision?
    What you should see

    Mini bat and magnet risks close. Ops can staff 6, not the 9 needed for hats at all five gates, so the signed 10,000-hat scope still fails Ops capacity.

  6. Optional: audio overview

    If the notebook's Content pane shows an Audio overview tile, select it to generate one for the briefing. It's a podcast-style summary for executives listening between meetings. Listen to the first minute: does it keep the CONFIRMED / ESTIMATE distinction?

Bottom of the 9th

Audience challenge · 4 minutes

Stump the Notebook

Ask the Command Center a question it cannot answer reliably from its references. Then name the exact missing source that would fix it. Points for questions that get a confident-sounding answer anyway.

Solo or pairs1 question eachName the missing source
Need ideas? Questions that should stump it
  • "How many Saturday tickets have we sold as of right now?" → needs a live ticketing report.
  • "What exactly does the fan email draft say about bucket hats?" → needs the email draft (Fan Experience).
  • "Did Elena approve the 10,000-hat version?" → needs Elena's email (the email export isn't a reference, on purpose).
  • "Which make-good does Riverbend prefer?" → needs sponsor correspondence; the contract says "sponsor's choice".
  • "Will it actually rain Sunday?" → needs a live forecast; the memo only gives a 60% chance.

Umpire review

Check the Command Center before you share it
  • Open two citations at random. Does the cited file actually say that?
  • Are the attendance figures labeled ESTIMATE, not fact?
  • After the 11 AM update, does the notebook still mention the 6/21 pallet as an open risk? (If so, it's mixing old and new.)
  • Who can see this notebook? Share it only with the Task Force.

The big idea

Curate the context

A notebook is a bench you pick on purpose: the right references, clear standing orders, and nothing else. Anything outside the notebook doesn't exist to it.

1

Curation beats volume

Fewer, more authoritative sources give more reliable answers. Adding everything "just in case" adds conflicts, like a draft plan against the locked one.

2

Instructions are standing orders

Notebook instructions set the role, format, citation rules and source hierarchy once, so every question inherits them.

3

Know the boundary

The notebook can't know today's ticket sales or whether staffing confirmed. The skill is noticing which question needs a source that isn't there.

Dugout notes

Dugout notes · instructor answer key

Timing (20 min): 3 min demo creating the notebook · 3 min instructions · 5 min briefing and questions · 3 min update · 4 min challenge · 2 min debrief.

Reference risk register (top 5 by impact):

  1. Weekend net drops below $2.4M once optional costs are added: plot twist base is $2,408,000, only $8,000 of headroom (budget model + memo).
  2. BRE deal as signed loses $30,900 and fails Ops capacity: 10,000 hats need 9 staff, with 6 confirmed after the update.
  3. Bobblehead shortfall of 600 against the guarantee: $8,100 to fix, or a $4,800 credit, or a replacement night (sponsor's choice).
  4. Fan email (180,000 recipients) mentions an item that isn't fully approved: reputational risk.
  5. Sunday weather: 4,500 fewer fans than plan, about $121,500 of net contribution.

Risk register gap: in our live test, Copilot left out the fan email risk and gave Sunday weather in fans only, so weather sorted below the $30,900 BRE drag. Follow up with: "Add any risks missing from this list, and convert fan impact to dollars at $27 net per fan." (4,500 fans × $27 = $121,500.)

Common miss: participants add the email export "for completeness." Then the notebook happily repeats Jordan's "it's approved" claims. Use that as a teaching moment on curation.

Staffing catch: the 11 AM update says the agency confirmed 6 staff, "not 9." But the Ops Playbook rule (+3 per dual-item gate × 5 gates) implies 15 for the redlined scope. Ask the notebook to check the memo against the playbook. A good answer flags the gap.

Mini bat conflict preview: if anyone asks how mini bats are distributed, the Event Plan says gate entry but Event Standards (not a notebook reference) says bat-style items go out at exit. Save the reveal for Inning 3.
