Before first pitch

Pregame checklist

  1. Pre-work: download the lab kits

    Grab the Session 1 kit and the Session 2 kit. Every file is fictional training material.

  2. Upload to OneDrive

    Extract both zips (Copilot can't read inside a .zip) into one folder named Rally Weekend Task Force, then drag it into OneDrive for Business. Choose Replace if asked about duplicates. Copilot in Excel needs workbooks saved in OneDrive or SharePoint with AutoSave on.

  3. Open Microsoft 365 Copilot

    Go to m365.cloud.microsoft/chat and make sure the Work mode is selected. Check that you can see Researcher and Analyst under Agents.

  4. Confirm feature access

    Notebooks, Agent Builder ("Create agent"), Pages and Scheduled prompts depend on license and admin settings. If one is missing, follow the lab's "Rain delay" alternative.

The rule of the game

Trust, but verify

Copilot is a great hitter. It is not the umpire.

Every inning ends with a verification step. Before an AI finding goes to leadership, run the 4-Base Verification Check:

1B · SourceCan I click through to the original email, file or row?
2B · StatusIs this a confirmed fact, a proposal, an estimate or an assumption?
3B · MathDid I independently re-check the totals, matches and exceptions?
HOME · GapsWhat did Copilot not see, and what would change the answer?
